# dev.txt
# General-purpose dev toolchain, separate from Datum's graphics-driver
# specific packages. gcc/clang/cmake/ninja/git/python/shellcheck/gdb are in base;
# languages beyond C/C++/Python are in languages.txt.
#
# docker           - container runtime
# docker-compose   - multi-container orchestration on top of docker
# postgresql       - relational DB server, for local dev databases
# sqlite           - embedded DB, lighter weight than spinning up
#                    postgres for quick scripts/prototypes
# direnv           - per-directory env var loading, useful for keeping
#                    project-scoped Nix devShells/flakes (per your
#                    existing Nix scoping rule) from leaking into the
#                    global shell
# valgrind         - memory error/leak detector, relevant given your
#                    weak spot is C++ specifically
# github-cli       - gh, GitHub from the terminal
